The bounded surface: flat fill, 1px hairline, 8–12px radius, never a drop shadow. `accent` adds the 3px left border (queue cards, authorship).

```jsx
<Card>…</Card>
<Card variant="row">in-flight row</Card>
<Card variant="dashed">empty state — a good state here</Card>
<Card accent="var(--held)">held queue card</Card>
```
